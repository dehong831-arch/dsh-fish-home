# 鱼的日常 · 小窝

把值得留下的对话，留成小窝里的一件东西。窗台、桌边、书架和墙上都有位置。点开物件，可以翻看它的来历、原话摘录和来源。

第一版从空屋开始，不预置共同回忆。植物、书、杯子、贝壳、信、票根都只是象征物，不代表 AI 有现实身体或与你共同经历了线下生活。

## 已实现

- 四个摆放区域、七种物件外观；最多保存 120 件，同时摆出 16 件。
- 点击回访；共同事件簿可搜索、编辑、收起与重新摆出。收起会保留原话和来历。
- 在对话中保存有原话支持的片段，或在面板手动补记；两种来源分开标示。
- 主机侧持久保存、上次正常版本备份、版本冲突保护、JSON 导出。
- 可关闭“对话里带上小窝”。关闭后不再注入物件索引，面板与工具仍然可用。

不另建情绪、记忆或提醒系统，与现有陪伴插件搭配使用。

## 兼容与安装

已按 DSH `0.2.1-rc.5` 的 Cordis、工具与系统提示接口实现，Node.js 建议使用 22 LTS 或更新版本。插件无第三方运行时依赖。Web 客户端通过 DSH 的设置扩展槽加载。

下载源码 ZIP 并解压，或用 Git 克隆仓库。请先确认当前 DSH 使用的 profile。以下以 `web` 为例；桌面端若使用 `web-desktop`，替换 profile 名称。

在插件源码目录打开 PowerShell，安装当前目录：

```powershell
$pluginPath = (Get-Location).Path
dsh plugin --profile web add "$pluginPath"
```

也可从仓库 Releases 下载 `dsh-fish-home-0.1.0.tgz`。在安装包所在目录打开 PowerShell：

```powershell
$pluginArchive = (Resolve-Path "./dsh-fish-home-0.1.0.tgz").Path
dsh plugin --profile web add "$pluginArchive"
```

安装命令会修改所选 profile，而不是只修改此源码目录。安装后保存手头工作，再重启相应 DSH 服务，并刷新页面。不要把网页刷新当成宿主重启。

打开 **设置 → 小窝**。也可从该页单独打开完整面板；路由是 `/plugins/dsh-fish-home/panel`。没有 Web 服务的纯终端 profile 不提供面板。

## 怎么用

对大肥鱼说想把刚才的一段话留下，选个象征物放进小窝。工具会核对原话是否出现在当前会话、本插件收到的真人输入中。以后让它看看那件东西，它可以取回原话再聊。

面板的“添一件”用于手动补记。写名称、物件种类、位置、来历、原话摘录；事件日期不知道就留空。手动记录不会冒充自动核验的对话来源。

保存后，点击屋里的物件或事件簿中的条目即可回访。在编辑里可换位置、修正说明或收起。对话记录的原话来源不可改写；手动补记可以修正摘录与日期。

## 原话核验的范围

插件只监听加载后实际收到的真人输入，不扫描旧会话、长期记忆、工具结果或子代理报告。每个会话在内存里保留最近 24 条符合条件的输入，最多 64 个会话；单条超过 32,000 字时不进入缓存。重启会清空此临时缓存，已经保存的物件不受影响。

对话保存要求 4–800 字的逐字摘录，且必须来自调用工具的同一会话。找不到出处会拒绝保存，可请用户重述，或由用户手动补记。

核验保证“摘录确实出现过”，不能自动判断来历说明的每一句是否受原话支持。说明仍应忠实于对话，支持在面板中修正。显示的“原话接收时间”是本插件收到输入的时间，不是事件发生日期，也不是消息发送时间。

## 数据与恢复

默认数据保存在 DSH 主目录下的 `fish-home/state.json`。若设置了 `DSH_HOME`，则使用该目录。它与现有长期记忆、情绪数据分开保存。

- `state.json`：当前物件与设置。
- `state.json.bak`：最近一次成功保存前的正常版本。从第二次修改开始生成。
- `state.json.lock`：跨进程写入锁，正常保存后立即移除。

数据只保存在运行 DSH 的主机。面板不加载外部字体、脚本、图片或统计服务。物件索引会在开关开启时进入模型上下文；原话在调用回访工具时返回模型。JSON 导出包含保存的原话与会话编号，请自行选择保存与分享的位置。

损坏或读取失败时，插件会报错并停止写入，不会自动创建空数据盖掉原文件。恢复前先停掉所有使用这个 DSH 主目录的实例，并备份 `fish-home` 目录，再把确认正常的备份复制为 `state.json`。备份可能比最后一次操作早一个版本。

若异常退出留下锁文件，确认所有相关 DSH 实例均已停止后，才能删除 `state.json.lock`。不要在仍有实例运行时移除锁。

旧页面保存遇到版本冲突会刷新状态并提示重新核对，不会自动重放旧的修改。

## 开发验证

```powershell
npm run check
npm test
npm pack --ignore-scripts
```

测试使用独立的临时小窝，不读取或改动真实陪伴数据。测试以同一 Node.js 进程运行，适用于限制子进程创建的环境。

工具：`fish_home_look` 回访或列索引，`fish_home_keep` 带原话留物，`fish_home_move` 换位置。面板 API 有同源检查、JSON 请求限制和乐观版本检查。插件不需要额外 API 密钥。
